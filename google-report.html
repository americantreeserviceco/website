        How to get your CSV from Google ▾
        1. Sign in to business.google.com/locations (Business Profile Manager).
        2. Tick the profile or profiles you want, then choose Download and the insights/performance report. Google moves these menus around, so look for "Download" near the profile list.
        3. Pick a date range (Google allows up to about 90 days per file) and download the CSV.
        4. Click Import CSV above. Google's file has totals for the whole range, so the dashboard asks which dates it covers. Use the range you picked in Google's dialog.

        Import one file per month (or per quarter) to build up history. Re-importing the same location and dates replaces the old numbers, so nothing is counted twice.

        Daily data works too: any CSV with a Date column and columns such as Google Search – mobile, Calls or Website clicks is read row by row. That covers exports from the Business Profile Performance API and most reporting tools.

        Search terms: a CSV with a Search term (or keyword) column and a count column fills the Top search terms table.
